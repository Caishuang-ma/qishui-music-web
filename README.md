# 汽水音乐宣传落地页

电脑端单页，共品牌、听歌场景、听歌模式及下载四屏，无二级页面。按用户最新要求，只针对电脑端设计与验收，基准画布1440×900，支持1024px以上桌面窗口。

静态HTML/CSS/JavaScript，打开dist/index.html或以dist为根目录启动静态HTTP服务，无需安装依赖或编译。

包含贯穿全页的流动曲线背景与指针视差、巨型标题入场、宣言带、八场景3D摄影圆环、默认/熟悉/新鲜三种模式切换、唱片旋转、封套视差与收藏气泡浮动。场景支持苹果触控板横向两指滑动、鼠标拖拽、左右按钮和方向键，手势连续推动圆环，停手后吸附。增加圆环半径和俯视角，缩小卡片，减少前后遮挡。没有页数提醒或产品截图展示。

第三屏点击播放按钮打开 Kate Bush 的 Running Up That Hill 官方完整版 YouTube MV，保留画面、原生控制栏、全屏及官方来源链接；关闭弹窗后移除播放器、停止播放并恢复焦点。没有下载、缓存或重新上传歌曲，播放依赖 YouTube 可访问性。

第四屏是黑底音乐海报：巨型双行标题、悬浮品牌物体与椭圆轨道、三张错位生活摄影及绿色下载票券。官方下载指向 https://music.douyin.com/qishui 。不把会员价格作为营销承诺。减少动态效果下信息完整、交互仍可用；后台和屏外暂停持续视觉动效。

设计参考 https://lenis.dev/ 与 https://pmndrs.github.io/examples/cards-with-border-radius/ 。圆环用原生CSS3D近似透视与悬停语言，未复制WebGL源码。新截图提供真实产品模式和场景分类依据。摄影出处见assets-sources.md；参考审计见reference-card-audit.md；最终验收见AUDIT.md。
